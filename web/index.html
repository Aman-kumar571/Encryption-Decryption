FileCrypt Browser Tool How It Works

Encrypt files with a password. Nothing leaves your device.

FileCrypt uses AES-256-GCM encryption with PBKDF2 key derivation. Your files and passwords never leave your computer. Available as a desktop app or directly in your browser.

What it is

FileCrypt is a file encryption tool. Pick a file, set a password, get an encrypted .fct file. To decrypt, use the same password. Works offline. No account needed. The desktop app and browser tool use the identical file format, so files encrypted in one can be decrypted in the other.

How to use in 3 steps

  1. Choose a file (or drag and drop into the application).
  2. Enter a password (minimum 8 characters for encryption).
  3. Click Encrypt or Decrypt.

Important: If you lose your password, your data cannot be recovered.

Use in your browser

No installation needed. The browser version uses the Web Crypto API locally on your device.
